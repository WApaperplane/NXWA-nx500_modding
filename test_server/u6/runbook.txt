#   R3-A  identity 表 → 取景器中性   ⇒ 表格式终验（R1 的最终闭环）

# 三条不可协商的纪律（继承 U1）：
#   1. telnet 一次会话只发一条命令；结果一律 FTP 拉，不信回显

#   b. 看取景器【决不半按快门】——半按会让 p7 抢回表指针（正常现象，不是回滚失败）
#   c. 写类命令（load/save）自动内嵌 cmasafe 四查（CMA 范围/事故黑名单/4KB 对齐/
#      全零）。被拒绝时【不要换地址硬上】——重跑 pick，等更安全的时机。
#   d. 与历史 10-07 实验相比，本次【唯一变量 = 表数据格式】（19652B {R,G,B,pad=0}），
#      sel/fmt/cbcr/settle 全部沿用历史成功参数 —— 出异常先查表，不要先动参数。

[1] 基线 + P8 结案补读（1 条命令，全只读）
==============================================================================
RUN: /usr/bin/setsid /bin/sh /mnt/mmc/u6/u6_probe.sh
WAIT: 60
验收：/mnt/mmc/u6/out/probe.log 存在，含 loadavg/ps 行数/diskstats/三路径 p8 sysfs
判据（写死）：
  * loadavg 与 ps 行数 = 后续一切"被拖垮"判断的参照物（铁律 104）
  * diskstats 里 mmcblk0p8 的 writes_completed 与 sectors_written；
    若【== 0 且 p8 class/ro == 1】（只读标志，或 force_ro == 1）
    ⇒ p8 '从未被写入 + 只读' 结案（对照 p9/p10/p11/p14 均有写入）
  * ★ 本脚本修正了 u1 的 sysfs 路径错误（/sys/block/mmcblk0p8/ 恒 N/A）：
    以 class/ 与 disk/ 两行为准；u1path 行留作对照（预期仍 N/A）
  ★ 若 class/ro 与 disk/ro 仍全部 N/A ⇒ 记录负结论"该内核未导出分区 ro 属性"，
    改用 diskstats 零写入作为唯一判据（不阻塞 U6）
