[1] 环境侦察 + 负载基线 + P8 定案判据（1 条命令，全只读）
==============================================================================
RUN: /usr/bin/setsid /bin/sh /mnt/mmc/u1/u1_probe.sh
WAIT: 60
验收：probe.log 里有 uptime/loadavg/ps 行数（后续判'拖垮'的参照物）、
      /dev/input 列表、p8 的 ro/start/size 与 /proc/diskstats
判据：diskstats 里 mmcblk0p8 的第 3 列(已读扇区)与第 7 列(已写扇区)；
      若【已写扇区 == 0】且 p8 ro=0  =>  p8 '从未被写入' 定案（P8_ZERO_INVESTIGATION）

[2] ① /dev/mem 四点对照（4 条命令）—— 顺序即判据，不要打乱
==============================================================================
★ 铁律 118：先阳性对照证明'方法在本机读得动'，再阴性对照，最后才问问题本体。
# idx=1  ctl_dram_94000000  0x94000000  768 regs -- 阳性对照：Linux CMA 窗口，已知 dd 可读
RUN: /usr/bin/setsid /bin/sh /mnt/mmc/u1/u1_rd.sh 1
WAIT: 90
# idx=2  ctl_dev_2082b000  0x2082b000  768 regs -- 阴性对照：设备寄存器区，预期 dd 失败
RUN: /usr/bin/setsid /bin/sh /mnt/mmc/u1/u1_rd.sh 2
WAIT: 90
# idx=3  lut_a_810fd100  0x810fd100  768 regs -- 问题本体：p7 LUT 缓冲 A
RUN: /usr/bin/setsid /bin/sh /mnt/mmc/u1/u1_rd.sh 3
WAIT: 90
# idx=4  lut_b_81115200  0x81115200  768 regs -- 问题本体：p7 LUT 缓冲 B（= LUT0）
RUN: /usr/bin/setsid /bin/sh /mnt/mmc/u1/u1_rd.sh 4
WAIT: 90
验收：每段 .bin 与 .log 落盘；.log 里 dd_rc=0 表示读成功
判据（写死，避免事后解释）：
  idx=1 读成功 + idx=2 读失败  =>  方法可用，'读不到'= 该地址面真的不可读
  idx=1 读失败                 =>  整套方法失效，回到离机轨（禁止输出主结论）
  idx=3/4 任一读成功           =>  G2a：走读已知内容的表做差分，U11 直接解
                                    D1 降级为交叉验证，lutmod 补丁永久弃用
  idx=3/4 都读失败             =>  G2b：才评估 lutmod，且必须重推目标地址
  ★ 把四个 .bin 的 md5 与大小抄进 raw8/gates/u1/mem_compare.json（gate_flow 读它判 G2）
