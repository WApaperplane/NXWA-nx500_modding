## 2. A2 块逻辑（80B @0x11530，逐指令已复核）

```
push {r4,r5,r6,lr}
r4 = id - 0x134
if r4 <= 6:  ldr r5,[r2]; r0 = 0xdc+r4; r1 = r5; bl 0x64f0c（写槽）; r0=0; return
if r4 == 7:  r0 = 0xda; r1 = 10; bl 0x64f0c（槽0xda=自定义1）; bl 0x51ab8（全链应用）; r0=0; return
else:        pop; b 0xd6b20（原路透传——老功能零影响）
```

**关键依据**（`PW_APPLY_TRIGGER_PREREQ` 预研）：
- 写槽 `FUN_00064f0c(slot,val)` = `*0x61aec(slot) = val`（一条 str）
- 应用 `FUN_00051ab8` **自包含**（push/pop 平衡）——**不可用 0x545b8**（它 `b 0x53bf4` 依赖通知器栈帧）
- 0x51ab8 内部自动完成：读 9 槽 → 编码（COLOR/SCALAR/LUT）→ `d6b20` ×8 → ISP
- 槽 0xda=10 ↔ 0x140009（"自定义1"）——提交前写定，保证应用语境正确
