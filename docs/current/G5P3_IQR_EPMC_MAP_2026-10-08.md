## 0. 一句话结论

> **epmc A/B 槽池 = ISP「流描述符」层（几何/格式/尺寸），iqr = 拍摄「状态镜像」层；
> 两层正交，唯一强锚点是图像尺寸（720×480 四处对上）。
> ⇒ 原设想的「路径 B：EP 直写 21 槽改画质」不成立——这 21 槽写的不是画质参数。**

## 1. 槽池结构（本轮静态实锤，全部可复核）

| 项 | A 池 | B 池 |
|---|---|---|
| 基址 | `0x20821300` | `0x20821700` |
| 写入器 | `FUN_004b6894` | `FUN_004b6b98` |
| 槽 | 21（`slot ≤ 0x14`）× stride `0x100` | 同左 |
| 通道 | 每槽 ch0(`+0x00`) / ch1(`+0x80`) | 同左 |
| 每通道字段 | `+0x00..0x24` 九个字（`+0x0c/+0x10` **读改写**，`+0x10` 强制 `\|0x30`） | 同左（同一描述符模板） |
| 运行时实测 | **4 槽全空**（仅版本戳 `0x13061809`） | s0 半满、**s1/s2/s3 满**（戳 `0x13060516`） |

- **提交**：写完调 `FUN_004ba6a8(slot+4)` ⇒ `*(u32*)0x20821044 = 1<<(slot+4)`
  ★ **修正记忆**：提交位图地址是 `0x20821044`（top 块 +0x1044），不是 `0x20820044`。
- **版本戳**：每槽尾 `+0xfc`（= ch1+0x7c）由**初始化器**写（写入器不碰），两种戳
  （A `0x13061809` / B `0x13060516`）⇒ **A、B 分开初始化，是两个独立池**。
- **调用者**：`FUN_00122ca0`（流配置器）——查属性句柄（`0x4110/0x4412/0x4512/0x4609/0x4612`…）
  → 属性总线 set + 双槽写入器，**开机/模式切换时配置流**，不是运行时调参入口。

## 2. 尺寸三元组 —— 唯一强锚点（三处编码同值）

B 池满槽每槽是一个**分辨率级**（4:3 金字塔）：

| 槽 | +0x08[31:12] | +0x20 (W-1,H-1) | +0x24/+0x28 (W,H) | 浮点对 +0x00/+0x04 (f32) |
|---|---|---|---|---|
| s1 | 720 | (719,479) | **(720,480)** | -0.0058 / -0.0060 |
| s2 | 528 | (527,351) | (528,352) | -0.712 / -0.723 |
| s3 | 384 | (383,287) | (384,288) | -0.766 / -0.773 |

- s1 的 (720,480) ↔ **iqr[15]/[16] `AF_IMAGE_SIZE_W/H` 与 iqr[74]/[75] `AE_IMAGE_SIZE_W/H`**（±0/±1 全对上）；
- s2/s3 的尺寸**不在 iqr**（子流私有）；
- 弱锚点：+0x08 的 lo16=0x51(81) ≈ iqr[24] `AF_RESULT_START_V`=80（±1，三槽同值，疑位域巧合）；
- 其余非零（浮点对、格式位域 `0x08000000`/`0x33`、`+0x40` 区块参数）＝ **流描述符私有，iqr 无对应**。

## 3. 架构判定与路径 B 修正

1. **两层正交**：iqr 184 ID 是"拍摄意图/状态"（AF/AE/WB 模式与结果），槽池是"ISP 流几何/格式"。改槽池 → iqr 几乎不动（除尺寸）；改 iqr → 槽池不动。**不能互为生效判据**（尺寸除外）。
2. **路径 B 语义修正**：原设想"EP 直写 21 槽 = 画质可编程入口"**降级**为"流描述符直写"。画质参数的已证入口仍是：
   - PW 7 维（`st cap capdtm varlist` 判据，见 `PW_PARAM_CHANNEL_2026-10-08.md`，已闭环）
   - 3D LUT（`0x2082b000` 窗口，idx 8，在用）
   - 属性总线（`set_attribute(0x10e/0x110/0x111/0x112)`，PW 确认动作走的它）
3. **消费判据仍然拿到**（G5-3 的真交付）：**尺寸锚点是完美的"被消费"判据**——
   上机最小实验：改 s1 `+0x24` 的 (720,480) → 若 liveview/AF 区域行为跟随 ⇒ 描述符被消费；
   iqr[15]/[16] 是否跟随可同时观察。这实验**风险低**（只读改写一个槽、可复位），
   但它验证的是**流几何通路**，不是画质通路。

## 4. 边界（铁律 119：说"没有"必须附完整性证明）

- 本表只覆盖 **0x1300..0x1b00**（B s0..s3）；**B s4..s20（0x1b00..0x2b00）从未读过**。
  依据（推断 s4+ 同构）：写入器模板 21 槽一视同仁；调用者只见 slot 0..3；3D LUT 有独立窗口。
  ⇒ "未扫区间"≠"空"，上机可一次 `epmc 0 0x2b00 nz 0x1300` 补全（单段 768 regs 上限内需分 2 段）。
- A 池空槽的语义（第二 ISP 通道？电影模式？）未验，仅记录。
