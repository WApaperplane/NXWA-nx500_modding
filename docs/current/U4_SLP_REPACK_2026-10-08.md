## 3. ★★ 段↔分区映射（本轮最有价值的离机成果）

方法：拿每个 SLP 段的 md5 去比对所有分区备份的**前缀**（已知锚点 `img5 = p7[:12075648]`）。

| img | len | magic | **对应分区** | 依据 |
|---|---|---|---|---|
| 2 | 3,176,040 | uImage | **p6**（uImage） | 前缀 md5 命中 |
| 3 | 6,169,816 | uImage | **p13**（rImage） | 前缀 md5 命中 |
| 4 | 117,184 | 偏移表 | **boot1** | 前缀 md5 命中 |
| 5 | 12,075,648 | ARM 向量表 | **p7**（rtos） | 前缀 md5 命中（已知锚点）|
| **8** | **28,672** | **全零** | ★ **p12（pcache）** | 前缀 md5 命中 |
| 0 / 1 / 6 / 7 / 9 | — | uImage / 向量表 / LZOP | 未命中 | 缺 p9/p10/p11/p14 备份；推断是 kernel 副本 / rootfs / opt / snapshot |

★ **规律：SLP 段 = 分区备份的前缀**（取该分区"有效内容"长度）—— 已由 5 段独立命中确认。

python raw8/fw/slp_pack.py patch .uploads/fw/nx500_v1.13.bin \

⇒ 等长；改的都是必要字段；其余 352 MB 分毫未动。

## 5. ★★ 风险评估：1.13 其实 ≈ 1.12

| 层面 | 设备(1.12) vs SLP(1.13) |
|---|---|
| uImage / rImage / boot1 / **p7** / pcache | **完全相同**（0 字节差异） |
| **rootfs（p10 / img6）** | **完全相同**（全量 diff：`Files differ = 0`） |
| `di-camera-app`、`libfirmware-upgrade.so` | **md5 完全相同** |
| `/etc/version.info` | 两边都写 `1.12 / NX500 / NX500GLU0APC1 / DSP_…_SR1 / BABF43A` |
| 未映射段 img0/1/7/9 | **未比对**（无对应分区备份） |

**推论**：
- 走一遍官方升级流程 ⇒ 实际效果 ≈ **原样重刷** + pcache 首字节变 `0x01`
- ★ **mod 主体在 `/opt/usr`（p14），而 p14 不在 SLP 的 10 段里** ⇒ 升级**不会碰它**
- ★ `rootfs` 是**只读挂载** ⇒ mod 本来就改不了它

⇒ U4 上机的实际代价**远低于初判**（原以为"不可逆的版本跃迁"，实际是"近似空操作"）。
