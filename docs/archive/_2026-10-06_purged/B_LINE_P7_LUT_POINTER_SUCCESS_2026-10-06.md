## 三、★ 新增的安全工具：`lutload.arm poke`

```bash
lutload.arm poke <phys_addr> <file>
```

**只往 CMA 物理内存写数据，绝不触碰任何 EP 寄存器。**

| 对比 | `import` | ★ `poke` |
|---|---|---|
| 写 CMA 内存 | ✅ | ✅ |
| 写 EP 寄存器 | ✅ | ★ **完全不碰** |
| 触发 DMA | ✅ | ★ **不触发** |
| 可能导致花屏 | 是 | ★ **结构上不可能** |
| 可能导致卡死 | 是 | ★ **结构上不可能** |

⇒ 这是铁律 61（探测空闲≠可独占）的正解落地：**不与硬件抢内存，只往里面放数据，让 p7 自己去取。**
